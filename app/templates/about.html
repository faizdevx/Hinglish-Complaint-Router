About

Purpose

A research / portfolio project that studies multilingual, code-mixed message routing with a multi-task NLP classifier: one shared encoder, three heads (intent, urgency, escalation). Routing is derived from the predicted intent. It is not an LLM wrapper; the classifier is trained and evaluated in this repository.

Architecture

text → normalise (NFC, whitespace)
     → tokenizer (MuRIL WordPiece)
     → shared encoder (BiLSTM | MuRIL)
        ├─ intent head      (77-way softmax)
        ├─ urgency head     (5-way softmax)
        └─ escalation head  (sigmoid → probability)
     → route = f(intent)   (src/routing.py)
language/script: Unicode rule + char-n-gram LR (en vs hi-Latn)

Dataset provenance

  • Intent: IndicJevBench fintech_banking77 (CC BY 4.0, cmul8). English = Banking77 (PolyAI); the 6 Indic languages are machine-translated (NLLB-200, per the dataset card). Banking support queries, not complaints per se.
  • Urgency / escalation: IndicJevBench synthetic_enterprise: synthetic, generated by LLMs (per its provenance field), Hindi (Devanagari) and Hinglish only. Not real customer data.
  • Not used for training: intent_massive (voice-assistant commands), hinglish_lid (script detection; only used to sanity-check the script rule).

Models

BiLSTM baseline (from scratch, compact vocabulary built from training text) vs MuRIL (google/muril-base-cased, Apache-2.0) fine-tuned end to end. Loss = λ₁·L_intent + λ₂·L_urgency + λ₃·L_escalation with λ = 1, each averaged over rows that carry that label (the datasets are disjoint: no text has both an intent and an urgency label).

Evaluation methodology

70/15/15 split with a fixed seed (no official split exists), duplicates grouped, stratified. Test split used once for reporting. Temperature scaling for the escalation probability is fitted on validation only. Latency = median single-message CPU time. Bootstrap intervals are shown for headline metrics.

Limitations

  • No labelled Hinglish intent data exists in the selected subsets, so Hinglish intent accuracy is not measured.
  • Urgency/escalation are learned from ~120 synthetic training texts; test sets have ~30 examples.
  • Intent taxonomy is banking-only; other domains will be mis-assigned.
  • Escalation probability is calibrated by temperature scaling on a tiny validation set; do not read it as a real-world risk.
  • Not for autonomous high-stakes decisions.

Technology stack

Python · PyTorch · Hugging Face Transformers · scikit-learn · FastAPI · Jinja2 · vanilla JavaScript · pytest. No external CDN or font is required.
